# kako-f.github.io
# Camilo Fuentes Beals — Portfolio

A single-page technical and research portfolio built with React, Vite, and TypeScript.

## Development

```bash
npm install
npm run dev
```

The development server prints its local address in the terminal.

## Production build

```bash
npm run build
npm run preview
```

`npm run build` writes the deployable site to `dist/`.

## Deployment

Push to `main`. The GitHub Actions workflow builds the site and deploys it to GitHub Pages. In the repository’s **Settings → Pages**, select **GitHub Actions** as the publishing source once.

The published site is available at [kako-f.github.io](https://kako-f.github.io/).
